# agentic-pong

Minimal browser Pong built as a small experiment in agentic software engineering.

## About

The game is intentionally small: one player, one computer opponent, one ball, three difficulty levels, and no unnecessary features.

The repository is equally intentional. It is designed to explore a compact, transparent workflow built around explicit product requirements, agent-readable engineering rules, automated verification, independent review, human playtesting, and continuous delivery.
